# DON'T ACT HUMAN Relay

Steamを使わない別拠点テスト用のWebSocket中継サーバーです。

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/KuzuYou/dont-act-human-relay)

1. 上の **Deploy to Render** を押します。
2. Renderで内容を確認してデプロイします。
3. 発行された `https://...onrender.com` を `wss://...onrender.com` に変更します。
4. ゲームの `ONLINE TEST / NO STEAM` へ同じURLを設定します。
5. ホストが部屋を作り、12文字コードを友達へ渡します。

無料枠は短時間の動作検証用です。ゲーム本体はこのリポジトリに含まれません。
